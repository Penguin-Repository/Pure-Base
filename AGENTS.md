# AGENTS.md

Pure-Base provides minimal independently usable base shaders for
[Shader-Core](https://github.com/lilxyzw/Shader-Core); it is a shader host and
foundation, not a feature-complete shader package.

The following three documents are continuations of these package rules, not
optional references. Before editing or validating any part of the package,
read all three. If any document is unavailable, stop before editing or
validation and report which document is missing or inaccessible:

* [Project and validation](.github/agent-guidance/project-and-validation.md)
* [Size policy](.github/agent-guidance/size-policy.md)
* [Licensing](.github/agent-guidance/licensing.md)

These package rules do not replace applicable workspace or user instructions.
